# jsasteroids

It's like Asteroids but in javascript.

I made this over a few days in June 2021 because I love Asteroids.
It's a pretty fun game that you can make without too much effort.

# Controls

|  Key  | Action                                                                   |
|-------|--------------------------------------------------------------------------|
|   ↑   | thrust                                                                   |
|   ↓   | break/reverse                                                            |
|   ←   | steer left                                                               |
|   →   | steer right                                                              |
| space | shoot                                                                    |
|   Z   | bullet nova (you have a limited number of these - save them for level 5) |
